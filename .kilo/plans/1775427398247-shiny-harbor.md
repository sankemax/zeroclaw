# Plan: Add Compact Mode to build_tool_instructions

> **Parent investigation:** `.kilo/plans/1775420927163-eager-river.md` (Section 11: Tool Injection Bloat, Section 10: Recommended Remediation Priorities). The full problem analysis (two injection points, current mitigations, resolution options) is documented there.

## Problem
`build_tool_instructions` (src/agent/loop_.rs:3423–3454) injects name + description + entire JSON `parameters_schema()` for every tool. No compact mode exists — the `compact_context` flag stops at `build_system_prompt_with_mode_and_autonomy` and never reaches here.

## Solution (Option A)
Thread `compact_context: bool` through and when true, inject only `- **{name}**: {desc}` (names + descriptions), skip JSON schemas entirely.

## Changes

### 1. Update `build_tool_instructions` function signature and body (loop_.rs:3423–3454)
- Add `compact_context: bool` parameter
- When `compact_context` is true, output only `- **{name}**: {desc}\n\n` 
- When false, keep existing behavior with full `Parameters: \`{}\`` line

### 2. Update call sites
- **Line ~3839** (`run()` function, single-shot/daemon mode):
  ```rust
  system_prompt.push_str(&build_tool_instructions(&tools_registry, Some(&i18n_descs), config.agent.compact_context));
  ```
- **Line ~4710** (`run()` function, interactive REPL mode):
  ```rust
  system_prompt.push_str(&build_tool_instructions(&tools_registry, Some(&i18n_descs), config.agent.compact_context));
  ```

### 3. Update test (loop_.rs:7938-7952)
- Update `build_tool_instructions_includes_all_tools` to pass `false` for compact_context to maintain existing behavior test

## Validation
- `cargo fmt --all -- --check`
- `cargo clippy --all-targets -- -D warnings`  
- `cargo test` (specifically the `build_tool_instructions_includes_all_tools` test)

## Risk Assessment
- **Risk**: Low — additive boolean parameter with well-defined behavior
- **Impact**: Reduces system prompt token count significantly when `compact_context: true`
- **Rollback**: Trivial — single function signature change
- **Side effects**: None — only affects system prompt generation when compact mode enabled
